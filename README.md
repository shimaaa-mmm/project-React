📖 Overview
This repository contains the source code for a modern GPT‑style landing page UI.

The goal of this project is to demonstrate how to build a visually appealing website using React components, modern layout techniques, and responsive design principles.

The project is beginner‑friendly while still introducing important frontend concepts used in real‑world development.


🚀 Features
Modern AI landing page UI
Fully responsive layout
Reusable React components
Clean project architecture
Smooth sections and modern gradients
Mobile‑first responsive design
Easy development with Vite

🧠 What You Will Learn
While building this project, you will learn:

Creating reusable React functional components
Structuring a scalable React project
Using Flexbox and CSS Grid for layouts
Applying the BEM CSS methodology
Designing modern UI elements such as gradients and sections
Building responsive layouts with media queries
Organizing assets and components efficiently
Preparing projects for production deployment

React 19

📦 Installation
Clone the repository:
git clone https://github.com/yourusername/gpt-ui-project.git

Go into the project directory:

cd gpt-ui-project

Install dependencies:

npm install


▶️ Running the Project
Start the development server:

npm run dev

Then open:
http://localhost:5173

📁 Project Structure

src/
